Veeam Kasten for Kubernetes
Fundamentals

You run Veeam Data Platform. Someone has just handed you Veeam Kasten for Kubernetes and a cluster of applications to protect with it. This course maps Veeam Kasten — Kubernetes backup, disaster recovery, and application mobility — onto the backup knowledge you already have, then takes you through deployment, ongoing maintenance, restores, and the daily admin routine.

Who this course is for

Backup admins new to Kubernetes

This course is for you if you administer Veeam Data Platform today and have just been tasked with implementing and running Veeam Kasten. You know backup jobs, repositories, retention, restore points, and the rhythm of keeping a protected estate healthy — on Windows and VMware, from a console you drive with a mouse. Kubernetes is the part that is new, and this course treats it that way.

Prerequisites: hands-on Veeam Data Platform administration experience — no Kubernetes knowledge assumed. Every Kubernetes concept is introduced from the VDP equivalent you already operate, and the course says so when a parallel breaks rather than smoothing it over. By the end you hold a working administrator's model: what to deploy, configure, watch, and how to get data back.

How to take it

Read, check, then move on

Each module opens with its objectives and a short concept overview, then works through its topics in sequence. Within a module, sections reveal one at a time: a Continue button at the end of the visible content opens the next section, and the chapter rail or any in-page link jumps ahead without losing your place.

Take the modules in the order listed below — Module 02 builds on the concept map from Module 01, and the deployment module leans on the Kubernetes vocabulary from Module 02. Each module closes with a short knowledge check; treat 80% or better as your signal to move on, and reread the section behind any question you missed. Your answers, visited sections, and revealed sections are saved locally in this browser, so a module picks up where you left off; nothing leaves your machine.

Course content

Course content

5 modules · designed to be taken in order
01

From Veeam Data Platform Admin to Veeam Kasten Admin

Why protecting Kubernetes is a different problem than protecting virtual machines, and the concept map that carries your Veeam Data Platform knowledge across: backup job to policy, backup repository to location profile, and the snapshot-versus-export distinction that has no tidy Veeam Data Platform equivalent. Closes with the editions and where Veeam Backup & Replication integration fits.

Concept map 5-question check
02

Kubernetes Foundations for Backup Admins

The Kubernetes vocabulary a backup admin needs and no more: clusters, pods, namespaces, StatefulSets, then persistent volumes, PVCs, StorageClass, CSI drivers, VolumeSnapshots, and Helm. Each concept is mapped to its Veeam Data Platform or VMware counterpart, with what it changes about how you back the workload up.

Kubernetes terms mapped 5-question check
03

Deploying and Configuring Veeam Kasten

The install, start to finish: prerequisites and the pre-flight checks you run before touching the cluster, the Helm-based deployment of Veeam Kasten, reaching and authenticating to the dashboard, integrating your storage, and creating a first location profile so exported data has somewhere to land.

Install walkthrough 5-question check
04

Maintaining Veeam Kasten Over Time

Day-two ownership of the platform itself: upgrades and how to think about version policy, monitoring Veeam Kasten as a workload on the cluster, where the logs and diagnostics live when something looks wrong, disaster recovery of Veeam Kasten's own catalog, and the housekeeping that keeps the deployment tidy.

Day-two operations 6-question check
05

Restores and Day-to-Day Administration

The work you do every week: building policies and scheduling them, then the restore paths — from a local snapshot, from an exported restore point, and by importing an application into another cluster — plus role-based access control (RBAC) basics and a daily and weekly routine for running Veeam Kasten.

Restore paths 5-question check

Finished all five modules?

There is no exam attached to this course. The next step is your own cluster: run one policy end to end, export a restore point, then restore the application somewhere else and time yourself.
